# Noam Arazi

I work on AI and data for the public sector — building LLM systems that do real work, measured with evals, with a human-in-the-loop for the decision making.

## Projects

**[job-desk](https://github.com/Noam-Arazi/job-desk)** — An agentic pipeline that scrapes job boards every morning, ranks postings through deterministic gates and an LLM analyst, tailors a CV for each, and delivers a shortlist to Telegram. It never applies on its own: the submit tool is denied at the dispatch point, and tests prove prompt injection can't route around it. Runs offline with `uv run desk demo`.

**[emerging-tech-taxonomy](https://github.com/Noam-Arazi/emerging-tech-taxonomy)** — Built for the Israel Innovation Authority's national technology foresight cycle. Embeddings, recursive clustering and LLM labeling turn a flat list of emerging technologies into a three-level taxonomy for expert review. In the 2025 cycle: 202 technologies into 12 families and 35 groups, in about ten minutes.
